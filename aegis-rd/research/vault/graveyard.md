# Graveyard

Killed hypotheses. One line each, so dead ideas don't get re-researched. A kill here
means a *clean* test failed - implementation failures (broken grid, bad config) get
fixed and rerun, not buried.

> [!warning] Resurrect only on a changed precondition, never a hunch
> Every kill is provisional against the substrate it was tested on. Resurrect only when a **named precondition it died on has actually changed** - most rows carry a `Re-entry:` clause, and that clause is the condition. Re-running the same test on the same substrate is not a resurrection; it is what this file exists to prevent.
