# Aegis RD Research Vault

Organizes the research campaign: useful sites, per-run diaries, deep papers, and scratchpad notes.

## Map

- [[site-index|Site Index]] - useful sites found, organized by category
- [[runs/README|Runs]] - per-strategy diaries `runs/<strategy>/<date>.md`; a run diary is for a strategy that clears the five-part test
- [[research/README|Research]] - the paper pipeline: one paper folder `research/<slug>/` per paper, built with the `academic-paper` skill (fills `phaseN_*/` at runtime)
- [[papers/README|Papers]] - the finished PDF of each paper (`papers/<slug>.pdf`), and nothing else
- [[research-legacy/README|Research (legacy)]] - the old single-file prose articles, kept verbatim
- [[notes/readme|Notes]] - research scratchpad: provisional, article-shaped findings we do not want to lose kept as stateful knowledge.
- [[graveyard|Graveyard]] - killed hypotheses, one line each, so dead ideas don't get re-researched

## Conventions

> [!tip] Creating things
> New run day: [[runs/README|Runs]] (run-diary template in `runs/_templates/`). New paper: [[research/README|Research]]. New scratchpad note: add a file in `notes/`.

- Filenames use kebab-case, no spaces
