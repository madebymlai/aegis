# Papers - finished PDFs

The final PDF of each paper, and nothing else: `papers/<slug>.pdf`. One flat reading shelf of
deliverables, kept separate from the pipeline in [[research/README|research/]].

When a run finishes, copy the PDF out of `research/<slug>/phase7_formatting/` to
`papers/<slug>.pdf`. The `.tex` / `.docx` / working artifacts stay in the paper folder.

The PDFs are git-ignored (regenerable from the pipeline); only this README is tracked.
