# Research (legacy) - the porting queue

The original single-file prose articles, kept verbatim. Each is a candidate for **porting**:
to promote one, run the `academic-paper` skill in a new [[research/README|paper folder]], feed
it the article's argument + sources, then link the result back here and to the `runs/` diary
where the idea was tested.

Author new prose in `notes/` and new papers in `research/` - never here.
