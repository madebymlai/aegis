# Local Label Playbooks

This directory is reserved for repo-controlled local label playbooks selected by stable ID.

Local playbook files are ignored by git by default. Train-mode labels currently use fixed label components; use `docs/examples/components/label_component_example.py` as the public authoring reference. Ignored files are not secret management; do not store credentials here, and force-add local research playbooks only after an intentional review.
