Problem — Invalid Candidate detection is computed in one module but consumed via a key set the runner must remember to thread into Window Evaluation; forget it and the Run silently degrades instead of failing.

Solution — the precompute store answers invalid_keys() itself, so detection and consumption sit behind one interface.

  • silent dependency defined out of existence
  • one module owns invalidity
  • evaluator tests drop store setup

Completes aegis-rd ADR-0010's intent — verdict logic in one place.
